{{- /* The home page hero's default variant from data/hero.json (schema: schemas/hero.schema.json). Returns the variant map; fails the build when "default" names no variant. assets/js/hero.js may swap in another at page load; see docs/hero-variants.md. */ -}} {{- $hero := site.Data.hero -}} {{- $match := where $hero.variants "id" $hero.default -}} {{- if not $match -}} {{- errorf "data/hero.json: default %q is not one of variants[].id" $hero.default -}} {{- end -}} {{- return index $match 0 -}}
