---
title: "Start every new troop on approval"
summary: "Turn on approval for a new troop's first runs. You see each post before it goes out, catch the targeting and wording mistakes while they are still free, then let it run on its own."
date: 2026-10-26
author: "Blowhorn team"
layout: article
tags: ["tips"]
---

A new troop is a bundle of untested decisions: the target list, the wording, the pace, the platform. Approval mode makes the first runs cheap to get wrong. Each post waits for your yes, so a wrong list or an awkward template costs you a rejected post instead of a published one.

Run on approval until a full cycle has posted exactly the way you pictured it. Then turn approval off and let the troop work. If you later change the list or the wording in a big way, that is a new troop in every way that matters: put approval back on for a run.
