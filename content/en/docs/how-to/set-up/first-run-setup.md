# Set up Blowhorn the first time

The guided setup walks you through setup one step at a time. It is a
preview today: open it from **try the guided setup (preview)** on the Setup
screen.

- **What works today:** connect Chrome with the extension's **Connect** link
  (`blowhorn://onboarding`) or `blowhorn setup` in Terminal. There is no
  pop-up, and launching the app writes nothing.
- **What the steps are:**
  - **Welcome:** Major Blowhorn reports for duty. Nothing is changed yet.
  - **Sign in:** sign in to your Blowhorn account, or create one. Both happen in
    your browser and bring you back to the app. See
    [Create a Blowhorn account](/docs/how-to/set-up/create-an-account/).
  - **Getting ready:** Blowhorn finds your Chrome profiles and adds its extension
    to each one quietly. You see a check per profile, then "Blowhorn is in all N
    Chrome profiles". See [Install the Chrome extension](/docs/how-to/set-up/install-the-chrome-extension/).
  - **Assign your troops:** choose which person posts from which Chrome profile.
    See [Map Chrome profiles](/docs/how-to/set-up/map-chrome-profiles/).
  - **Connect accounts:** sign in to each platform yourself in Chrome. See
    [Platform accounts](/docs/how-to/set-up/platform-accounts/).
  - **First post:** preview it, then post. See [Post content](/docs/how-to/publish/post-content/).

## Going back and forward is safe

- **Next checks first:** each step checks that its work is really done (you're
  signed in, the extension is in every profile, your mapping is saved) before
  it lets you go on. If it isn't, the step says why, right under the button.
- **Back never redoes harmful work:** going back and forward again skips what's
  already done. The extension is never installed twice, sign-in is not
  repeated while you're signed in, and your first post is never sent twice.
- **Re-checking is fine:** finding profiles again and changing a mapping are
  safe to repeat.
