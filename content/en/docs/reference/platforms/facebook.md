**Coming soon.** Facebook isn't available in Blowhorn yet. When it is, Blowhorn
will work on Facebook in your own signed-in Chrome, and this page will list what
it can do there.

## Supported actions

None yet. Facebook is coming soon, so `blowhorn post` doesn't support
it today. See [All platforms](/docs/reference/platforms/) for the platforms you can use now.
